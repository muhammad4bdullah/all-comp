📘 CHAPTER 1 — COMPUTER SYSTEMS & DATA COMMUNICATION
Final Exam Notes
1. Computer

A computer is a programmable electronic device that performs arithmetic and logical operations automatically according to instructions provided by the user.

2. History / Early Computing Devices
Abacus

One of the earliest calculating devices, using beads for counting and basic arithmetic.

Napier's Bones

Invented by John Napier. Numbered rods used mainly for multiplication and division.

Pascaline

Invented by Blaise Pascal in 1642. A mechanical calculator using gears for automatic calculations.

Step Reckoner / Leibniz Wheel

Developed by Gottfried Wilhelm Leibniz in 1673. Improved upon the Pascaline using wheels and gears.

Difference Engine

Designed by Charles Babbage for performing mathematical calculations.

Analytical Engine

Also designed by Charles Babbage. Included concepts similar to modern computers such as:

Input using punched cards
Memory
Processing
Output

Charles Babbage = Father of Computer

Hollerith Tabulating Machine

Developed by Herman Hollerith. Used punched cards to process statistical data.

Differential Analyzer

Developed by Vannevar Bush for solving mathematical problems.

Harvard Mark I

Developed by Howard Aiken in 1944. A large electromechanical computer using switches, punched cards, and an electric typewriter for output.

7. CPU

CPU (Central Processing Unit) is the main processing unit responsible for executing program instructions.

It consists mainly of:

Control Unit (CU)

Controls and coordinates the activities of the computer.

Arithmetic Logic Unit (ALU)

Performs:

Arithmetic operations
Logical operations
Registers

Small, high-speed storage locations inside the CPU.

8. CPU Registers
MAR — Memory Address Register

Stores the address of the memory location being accessed.

MDR — Memory Data Register

Stores data/instructions being transferred to or from memory.

AC — Accumulator

Stores intermediate arithmetic and logical results.

PC — Program Counter

Stores the address of the next instruction to be executed.

CIR — Current Instruction Register

Stores the current instruction being processed.

9. Von Neumann Architecture

Developed by John von Neumann in 1945.

Its important feature is the stored-program concept, where instructions and data are stored in the same memory.

Main components:

ALU
Memory
Registers

17. Instruction Cycle

The CPU follows three basic stages:

Fetch → Decode → Execute

Fetch: Retrieve instruction from memory.
Decode: Determine what the instruction means.
Execute: Perform the required operation.
18. Pipelining

Pipelining allows multiple instructions to be processed at different stages simultaneously, improving CPU efficiency.

Interrupt

A signal that temporarily causes the CPU to stop its current activity and handle an important event/request.

Parallelism

Processing multiple tasks or parts of tasks simultaneously.

28. Programming Languages

A programming language is a structured method of communicating instructions to a computer using predefined commands, syntax, and rules.

Two categories:

Low-level languages
High-level languages
29. Low-Level Languages

Machine-oriented languages closely related to computer hardware.

Machine Language
Directly understood by computer
Written in binary
Difficult for humans to read/write
Assembly Language
Uses symbolic codes called mnemonics
Easier than machine language
Must be converted into machine code using an assembler
Allows hardware-specific programming

Assembly → Assembler → Machine Code

30. High-Level Languages

Designed to be easier for humans to read and write.

Examples: C, Java, Pascal, Visual Basic.

Procedural / Structured Programming

Programs are divided into smaller modules, each performing a specific task.

Three basic structures:

Sequence → instructions execute in order
Selection → choose based on a condition (if, else, switch)
Repetition → repeat instructions using loops

Object-Oriented Programming

Programming approach based on objects containing data and related behavior.

Examples: Student, Car, BankAccount.

31. Data Communication

Data communication is the exchange of data between two or more devices through a wired or wireless medium.

Components
Sender — sends the message.
Message — data being transmitted.
Medium — pathway used for transmission.
Receiver — receives the message.
Protocol — rules governing communication.
32. Communication Modes
Simplex

One-way communication.

Example: Server → Client

Half-Duplex

Two-way communication, but not simultaneously.

Example: Walkie-talkie

Full-Duplex

Two-way communication simultaneously.

Example: Telephone call

33. Asynchronous & Synchronous Transmission
Asynchronous
Data transmitted one character/byte at a time.
Uses start and stop bits.
Generally slower due to additional control bits.
Synchronous
Data transmitted in synchronized blocks/streams.
Does not require start/stop bits for every character.
Generally faster.
Requires synchronization between sender and receiver.
34. Communication Devices

Switch

Connects devices in a LAN and forwards data to the intended device/port.

Switch = Specific device

Data Packet

A small unit of data transmitted across a network. Data can be divided into packets and reassembled at the destination.

Router

Connects different networks and selects an appropriate path for forwarding data packets.

Router = Connects networks + chooses path

Gateway

Connects networks using different communication protocols.

Gateway = Different protocols

36. Types of Networks
LAN — Local Area Network

A network covering a small geographical area, such as a building or group of nearby buildings.

Characteristics:

Small physical area
High-speed communication
Wired or wireless
Usually fewer computers
Commonly used for sharing printers, files, applications, etc.

Memory: LAN = Small Area

WAN — Wide Area Network

A network covering a large geographical area, such as cities, countries, or continents.

Characteristics:

Large physical area
Can connect multiple LANs
May use leased lines, satellites, or public networks
Generally slower than LAN
More complex, so communication errors can occur

Memory: WAN = Wide Area

MAN — Metropolitan Area Network

A network larger than a LAN but smaller than a WAN.

Can cover a large campus or city.
Connects multiple LANs.
Usually provides high-speed communication.
Often uses fiber-optic connections.
Typically covers several to tens of kilometers.

Memory: MAN = City-sized

VPN — Virtual Private Network

A network that provides secure remote access to an organization's network using public infrastructure such as the Internet.

Characteristics:

Uses public networks
Secure remote access
Allows access to organizational resources
Can support file sharing/video conferencing
Cheaper than dedicated leased lines for remote access

Memory: VPN = Private connection over public Internet

39. Network Topology ⭐

Network topology is the arrangement of network nodes/devices and the connections between them.

1. Bus Topology

All devices are connected to a single main cable (backbone).

Advantages:

Simple
Requires less cable
Relatively inexpensive

Disadvantages:

Failure of main cable can affect the whole network
Performance decreases as devices increase
Troubleshooting can be difficult

Memory: 🚌 One main road.

2. Star Topology

All devices connect to a central device, usually a switch or hub.

Advantages:

Easy to install/manage
Failure of one device usually doesn't affect others
Easy to identify problems

Disadvantage:

Failure of central device can affect the whole network
Requires more cable

Memory: ⭐ Everything connects to the center.

3. Ring Topology

Each device connects to two neighboring devices, forming a ring.

Advantages:

Data travels in an organized manner
Equal access for devices

Disadvantages:

Failure of one connection/device can disrupt the network
Adding/removing devices can be difficult

Memory: 💍 Circle.

4. Mesh Topology

Devices are connected to multiple or all other devices.

Advantages:

Highly reliable
Multiple paths for data
Failure of one connection does not necessarily stop communication

Disadvantages:

Expensive
Requires lots of cables/connections
Complex to install

Memory: 🕸️ Web.

5. Tree Topology

Devices are arranged in a hierarchical structure, combining characteristics of star and bus topologies.

Advantages:

Easy to expand
Suitable for large networks
Easier management of groups

Disadvantages:

More complex
Failure of higher-level connections can affect sections of the network

Memory: 🌳 Branches.

6. Hybrid Topology

A combination of two or more different topologies.

Example: Star + Bus.

Advantage: Flexible and scalable.

Disadvantage: More complex and expensive.

40. Circuit Switching vs Packet Switching ⭐
Circuit Switching

A dedicated communication path is established between sender and receiver before communication begins.

The path remains reserved for the duration of the communication.

Example: Traditional telephone networks.

Advantages
Dedicated path
Predictable connection
Continuous transmission
Disadvantages
Wastes resources when no data is being transmitted
Connection setup required
Less efficient for bursty data

Memory:
Circuit = One dedicated road for the whole conversation.

Packet Switching

Data is divided into small packets before transmission.

Each packet may travel through different routes and is reassembled at the destination.

Example: Internet.

Advantages
Efficient use of network resources
No dedicated path required
Multiple users can share network links
Suitable for Internet/data communication
Disadvantages
Packets may arrive at different times
Packets may take different routes
Network congestion can cause delays

Memory:
Packet = Data broken into pieces and sent through the network.

Main Difference
Circuit Switching	Packet Switching
Dedicated path	No dedicated path
Path reserved	Resources shared
Continuous connection	Data divided into packets
Traditional telephone networks	Internet
Less efficient for bursty data	Efficient for data networks
41. Data Communication Standards

Data communication standards are rules/protocols that define how data is transmitted, received, and processed between computers and networks.

The International Organization for Standardization (ISO) developed the OSI reference model.

42. OSI Model ⭐⭐⭐

OSI = Open Systems Interconnection

It has 7 layers.

From top to bottom:

Application → Presentation → Session → Transport → Network → Data Link → Physical

1. Application Layer

Provides network services directly to applications/users.

Examples: Web, email, file-transfer services.

2. Presentation Layer

Handles the format and representation of data.

Functions include:

Translation
Encryption/decryption
Compression

Memory: "How should the data look?"

3. Session Layer

Establishes, manages, and terminates communication sessions between devices.

Memory: "Start/manage/end the conversation."

4. Transport Layer

Provides end-to-end data delivery.

Functions include:

Segmentation
Flow control
Error control
Reliable delivery

Memory: "Make sure data gets there properly."

5. Network Layer

Determines paths and handles logical addressing/routing of packets.

Memory: "Which route?"

6. Data Link Layer

Provides reliable transfer between directly connected devices and handles frames/MAC addressing.

Memory: "Device-to-device."

7. Physical Layer

Transmits raw bits (0s and 1s) through the physical medium.

Deals with:

Cables
Signals
Connectors
Physical transmission

Memory: "Actual wires/signals."

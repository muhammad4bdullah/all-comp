# Chapter 4 — Data Science & Big Data

## 1. Data

**Data** is a collection of facts, information, or observations about something.

Data can be represented as:

* Numbers
* Measurements
* Words/descriptions
* Sound
* Pictures
* Videos

---

## 2. Data Analytics

**Data analytics** is the process of examining and studying data to:

* Identify patterns
* Extract useful insights
* Draw conclusions
* Make data-driven decisions

It may use mathematical calculations, statistics, charts, graphs, and other tools.

**Example:** Recording temperatures throughout a day and creating a graph to determine how temperature changes.

---

# 3. Data Science

**Data Science** is an interdisciplinary field that combines **mathematics, statistics, data analytics, and machine learning** to analyze data and extract useful knowledge and insights.

### Data Science Pipeline

**Data → Analysis → Patterns/Knowledge → Insights → Informed Decisions**

It can be used to solve real-world problems.

---

# 4. Key Concepts of Data Science

### 1. Data

Collection of observations, facts, or information from different sources.

It may be:

* Structured
* Unstructured

Examples: numbers, words, audio, video, tweets, PDFs.

### 2. Dataset

A **structured or processed collection of related data**, usually prepared for a particular purpose.

**Example:** A collection of brain CT scans used to identify patterns in brain tumors.

### 3. Statistics

The study and analysis of the characteristics and frequency of past data/events.

### 4. Probability

The likelihood or possibility of future events occurring.

**Memory:**
Statistics → Past
Probability → Future

### 5. Mathematics

A fundamental part of data science used to:

* Solve problems
* Optimize models
* Interpret complex data
* Support decision-making

### 6. Machine Learning

A branch of AI/computer science that uses **data and algorithms** to enable computers to learn from data and perform tasks.

### 7. Deep Learning

A subset of Machine Learning that uses **artificial neural networks** to model aspects of human brain learning.

### 8. Data Mining

The process of discovering **patterns and relationships** in existing datasets.

### 9. Big Data

Very large and complex amounts of data that may be difficult for traditional data-processing systems to handle.

### 10. Predictive Analysis

Uses **historical data** to predict future trends or events.

### 11. NLP

**Natural Language Processing** is the study of interaction between **human language and computers**.

Applications:

* Chatbots
* Language translation
* Sentiment analysis

# 7. Types of Data

## A. Qualitative / Categorical Data

Describes objects or groups using **categories or labels**.

Examples:

* Colors
* Cities
* Grades
* Transport types
* Survey responses

### 1. Ordinal Data

Categories have a **meaningful order/ranking**.

Example:
**A > B > C > D > E > F**

**Memory:** Ordinal = **Order**

### 2. Nominal Data

Categories have **no meaningful order**.

Examples:

* Car, bus, train
* Red, blue, green
* Lahore, Karachi, Islamabad

**Memory:** Nominal = **Name/label**

---

## B. Quantitative / Numerical Data

Data represented using numerical values that can be mathematically analyzed.

Examples:

* Height
* Weight
* Number of students
* Growth rate

### 1. Discrete Data

Values that are **separate and countable**.

Example:
Number of students = 20, 21, 22...

**Memory:** Discrete = **Count it**

### 2. Continuous Data

Values that can take **any value within a range** and can be measured to greater precision.

Examples:

* Length = 11.5 cm
* Weight = 15.92 kg
* Temperature = 23.47°C

**Memory:** Continuous = **Measure it**

### Data Hierarchy

**Data**
→ Qualitative/Categorical
→ Ordinal / Nominal

**Data**
→ Quantitative/Numerical
→ Discrete / Continuous

---

# 8. Sources of Data

## Primary Data

Data collected **directly from the original source/respondent** for a specific purpose.

Methods:

* Surveys
* Questionnaires
* Interviews
* Experiments
* Direct observation
* Sensors
* IoT devices
* Biometric devices

**Memory:** Primary = **Personally collected**

### Respondent

A person from whom information is collected during a survey or inquiry.

---

## Secondary Data

Existing data that was **collected by someone else**, often for another purpose.

Sources:

* Government records/reports
* Books
* Journals
* Research papers
* Websites
* Online databases
* Previously conducted surveys/questionnaires

**Memory:** Secondary = **Someone already collected it**

---

# 9. Database

A **database** is an organized collection of data stored electronically so that it can be easily **accessed, managed, and updated**.

It can contain thousands or millions of records.

---

# 10. Dataset vs Database

### Dataset

A collection of related data prepared for a **specific purpose**, such as analysis or machine learning.

### Database

An organized electronic system for **storing, accessing, managing, and updating data**.

---

* Maintaining data

---

# 17. Big Data

**Big Data** refers to very large and complex datasets that traditional data-processing software may struggle to manage.

## Three Vs of Big Data

### 1. Volume

The **amount/quantity** of data.

**Volume = How much?**

### 2. Velocity

The **speed at which data is generated, received, or processed**.

**Velocity = How fast?**

Example: Real-time IoT data.

### 3. Variety

The **different types and formats** of data.

**Variety = How many types?**

### Types of Data in Big Data

**Structured:** Organized in tables/relational form.

**Unstructured:** Text, images, videos, etc.

**Semi-structured:** Has some organization but is not stored in traditional tables.

Examples:

* JSON
* XML

### Memory:

**Volume = Amount**
**Velocity = Speed**
**Variety = Types**

# 24. Challenges of Big Data

### 1. Data Quality

Poor-quality data can cause:

* Errors
* Inefficiency
* Misleading insights

### 2. Data Security & Privacy

Protecting massive datasets from unauthorized access while maintaining privacy is difficult.

### 3. Rapid Growth of Data

Data continues to grow rapidly, requiring systems capable of handling increasingly large amounts of data.

### 4. Big Data Tool Selection

Choosing compatible tools that can interact smoothly with different platforms can be challenging.

### 5. Data Integration

Combining data from different sources with different formats and structures can be difficult.

### Memory:

**Quality → Security → Growth → Tools → Integration**
